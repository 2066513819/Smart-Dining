# 供应商价格表导入工具使用说明

## 概述

`import_supplier_price_table.py` 是一个通用工具，用于从 Excel 价格表中提取食材信息并导入到数据库的 `l1_categories`、`l2_categories`、`ingredient_l1_catalog` 和 `ingredient_l2_catalog` 表中。

## 特点

1. **灵活的列名映射**：自动识别多种可能的列名（如"一级分类"/"大分类"/"主分类"等）
2. **智能分类管理**：自动匹配现有分类，不存在则自动创建
3. **单位标准化**：自动将各种单位格式标准化为统一格式
4. **增量更新**：已存在的食材价格会自动更新，新的会插入
5. **详细统计**：导入完成后提供完整的统计报告

## 使用方法

### 1. 预览数据（不导入）

在正式导入前，建议先预览数据，确认列名映射是否正确：

```bash
cd scripts
python import_supplier_price_table.py "26年1月商品入库价格表.xlsx" --preview
```

输出示例：
```
====================================================================================================
📊 文件预览: 26年1月商品入库价格表.xlsx
====================================================================================================
总行数: 150
列名: ['一级分类', '二级分类', '食材名称', '单位', '价格', '备注']

📋 列名映射检测:
  l1_category          -> ✓ 一级分类
  l2_category          -> ✓ 二级分类
  ingredient_name      -> ✓ 食材名称
  unit                 -> ✓ 单位
  price                -> ✓ 价格
  remark               -> ✓ 备注

📄 前 10 行原始数据:
...
```

### 2. 导入数据

确认预览结果正确后，执行导入：

```bash
python import_supplier_price_table.py "26年1月商品入库价格表.xlsx"
```

程序会提示确认：
```
====================================================================================================
即将导入数据到数据库，请确认:
  文件: 26年1月商品入库价格表.xlsx
  总行数: 150
  批次大小: 100
====================================================================================================

是否确认导入? (yes/no): yes
```

### 3. 指定工作表

如果 Excel 文件包含多个工作表，可以指定要导入的工作表：

```bash
python import_supplier_price_table.py "价格表.xlsx" --sheet "Sheet2"
```

### 4. 自定义数据库连接

如果需要使用其他数据库连接：

```bash
python import_supplier_price_table.py "价格表.xlsx" --db-url "mysql+pymysql://user:pass@localhost/food_db"
```

## 常见问题

### Q1: 列名没有被正确识别怎么办？

A: 在预览模式下，查看"列名映射检测"部分，确认列名是否在支持的列表中。如果使用的是特殊列名，可以修改 Excel 文件的列名，或联系开发者扩展 `COLUMN_MAPPINGS` 配置。

### Q2: 导入后发现分类不对怎么办？

A: 
1. 首先检查 Excel 文件中的分类名称是否正确
2. 如果分类已存在但匹配错误，可以手动在数据库中调整 `l1_categories` 和 `l2_categories` 表的对应关系
3. 重新导入时会根据名称自动匹配，不会重复创建

### Q3: 如何处理同一食材有多个价格的情况？

A: 工具默认采用"覆盖更新"策略：
- 如果 (食材名称, 分类) 组合已存在，会更新价格和单位
- 如果希望在更新时保留历史价格，需要在导入前备份数据

### Q4: 可以导入多个月份的价格表吗？

A: 可以。每次导入都会更新现有价格，不会影响之前导入的其他月份数据。建议在备注字段中标注价格日期，便于追溯。

### Q5: 导入失败如何排查？

A: 
1. 检查数据库连接是否正常
2. 确认 `.env` 文件中的数据库配置是否正确
3. 使用 `--preview` 模式检查数据格式
4. 查看错误日志中的具体错误信息

## 导入后验证

导入完成后，可以通过以下 SQL 查询验证数据：

```sql
-- 查看一级分类统计
SELECT l1.name, COUNT(*) as ingredient_count
FROM ingredient_l1_catalog i
JOIN l1_categories l1 ON i.l1_code = l1.code
GROUP BY l1.name;

-- 查看二级分类统计
SELECT l1.name as l1_name, l2.name as l2_name, COUNT(*) as ingredient_count
FROM ingredient_l2_catalog i
JOIN l1_categories l1 ON i.l1_code = l1.code
JOIN l2_categories l2 ON i.l2_code = l2.code
GROUP BY l1.name, l2.name;

-- 查看最近导入的食材
SELECT * FROM ingredient_l1_catalog
ORDER BY updated_at DESC
LIMIT 20;
```
