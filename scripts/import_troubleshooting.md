# 供应商价格导入问题排查指南

## 问题描述

点击"导入成本表格"按钮后，提示：
```
未找到有效的名称和价格数据，请检查列名（如：食材名称、单价）
```

## 可能的原因和解决方案

### 原因 1：后端服务未重启（最常见）

**现象**：前端调用了旧的 API，返回旧的错误消息

**解决方案**：
```bash
# 1. 停止当前运行的后端服务
# 2. 重新启动
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 或者如果使用 PowerShell
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

**验证方法**：
1. 打开浏览器访问：`http://localhost:8000/docs`
2. 查找是否有以下接口：
   - `POST /supplier-price-import/preview-supplier-prices`
   - `POST /supplier-price-import/import-supplier-prices`
3. 如果没有，说明后端未正确加载新代码

### 原因 2：浏览器缓存

**现象**：前端页面还是旧版本，调用了旧的 API

**解决方案**：
1. 刷新浏览器页面：`Ctrl + F5`（强制刷新）
2. 或者清除浏览器缓存后重新访问
3. 打开浏览器开发者工具（F12）→ Network 标签，确保没有缓存

### 原因 3：Excel 表格列名不匹配

**现象**：后端无法识别 Excel 表格的列名

**排查方法**：

#### 步骤 1：查看 Excel 实际列名
打开 Excel 文件，查看第一行的列名。常见的列名格式：

✅ **可以识别的格式**：
- 一级分类、食材名称、价格、单位
- 分类、品名、单价、规格
- 大类、商品名称、金额、计量单位
- 类型、名称、成本、单位

❌ **可能无法识别的格式**：
- 编号、日期、供应商、总金额（这些不是食材级别的列）
- 使用缩写或代码作为列名

#### 步骤 2：使用预览功能
1. 点击"预览表格"按钮
2. 选择 Excel 文件
3. 查看弹出的预览对话框：
   - 文件名是否正确
   - 总行数是否正确
   - 列名识别情况：
     - 一级分类 ✓/✗
     - 食材名称 ✓/✗
   - 检测到的列名映射

#### 步骤 3：根据提示调整列名
如果预览显示某些列未检测到，修改 Excel 列名为标准名称：

| 系统需要的字段 | 推荐使用的列名 |
|--------------|--------------|
| **一级分类**（必需） | 一级分类、大分类、分类、类型、品类 |
| **食材名称**（必需） | 食材名称、品名、名称、商品名称、货品名称 |
| 价格（可选） | 价格、单价、金额、入库价、成本价 |
| 单位（可选） | 单位、规格、计量单位 |
| 二级分类（可选） | 二级分类、小分类、子分类 |

### 原因 4：Excel 格式问题

**现象**：文件无法读取或解析

**排查方法**：
1. 确保文件是标准的 `.xlsx`、`.xls` 或 `.csv` 格式
2. 确保第一行是列名（标题行）
3. 数据从第二行开始
4. 没有合并单元格
5. 没有复杂的公式或图表

### 原因 5：API 路径错误

**现象**：前端调用的 API 地址不正确

**排查方法**：

打开浏览器开发者工具（F12）：
1. 切换到 Network（网络）标签
2. 点击"导入成本表格"按钮
3. 查看请求信息：
   - 请求 URL 应该是：`http://localhost:8000/supplier-price-import/import-supplier-prices`
   - 如果 URL 是 `/ingredient_prices/bulk-save`，说明前端代码还是旧版本
   - 请求方法应该是：`POST`

## 调试信息收集

如果以上方法都无法解决问题，请收集以下信息：

### 1. 后端日志
运行后端时添加调试模式：
```bash
# 查看详细日志
uvicorn app.main:app --reload --log-level debug
```

或者在代码中添加日志：
```python

logger.info(f"接收到的文件: {file.filename}")
logger.info(f"文件大小: {len(contents)} bytes")
logger.info(f"检测到的列: {columns}")
```

### 2. 浏览器控制台日志
1. 打开浏览器开发者工具（F12）
2. 切换到 Console（控制台）标签
3. 点击"导入成本表格"
4. 查看红色错误信息
5. 截图或复制所有错误信息

### 3. 网络请求信息
1. 打开浏览器开发者工具（F12）
2. 切换到 Network（网络）标签
3. 点击"导入成本表格"
4. 找到失败的请求（红色）
5. 查看请求的 URL、状态码、响应内容
6. 截图或复制相关信息

### 4. Excel 文件信息
1. 打开 Excel 文件
2. 截图第一行（列名）
3. 截图前3-5行数据
4. 提供文件格式（.xlsx / .xls / .csv）
